# Publisher API

## Requirements

- nodejs latest version
- pnpm latest version

### Run Application steps

## 1 - Run api

```bash
cd api
pnpm api
```

## 2 - Run app

```bash
cd app
pnpm run dev
```

- در ابتدا ساختار پروژه تعیین شد
- در قدم بعدی ابتدا تایپ ها اماده شد و AI نوشت
- سپس با توجه به API با TanstackQuery هوک ها با گفتن ساختار به AI آماده شد
- نمای برد با قابلیت drag اضافه شد با تدوین کد های AI
- آماده کردن schema ها برای افزودن و ویرایش با ساختار تعیین شده توسط AI
- تعیین فلو آپدیت دسته ای و پیاده سازی با تدوین کد های ارائه شده توسط AI
- تشخیص بهترین عملکرد برای ctrl+z و فلو آن و دریافت کدها AI و تدوین آن
- نوشتن منطق برای تداخل پست ها با کمک نوشتاری AI
- اماده سازی و نوشتن تست ها و کمک برای تنظیمات پیکربندی vitest از AI
